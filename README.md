# Booking Service

Сервис для бронирования переговорных комнат на Go. Администраторы управляют комнатами и расписаниями, а пользователи смотрят свободные слоты, создают и отменяют брони.

Доступ разделён по ролям `admin` и `user`. Авторизация работает через JWT. Сервис поддерживает регистрацию, вход по email и паролю и тестовый `dummyLogin`.

Основной стек - Go, Echo, PostgreSQL, pgx и Docker Compose.

## Запуск

Запустить сервис и PostgreSQL:

```bash
make up
```

Сервис будет доступен на `http://localhost:8080`. Проверить запуск можно запросом `GET /_info`.

Остановить проект:

```bash
make down
```

## API

API включает работу с пользователями, комнатами, расписаниями, слотами и бронированиями. Полный контракт находится в `api.yaml`.

Слоты длительностью 30 минут создаются по расписанию комнаты. Фоновый воркер запускается вместе с сервисом и обновляет слоты каждые 6 часов на 14 дней вперёд. Для даты за пределами этого окна слоты создаются при запросе, но не дальше настроенного горизонта бронирования. Настройки находятся в `resources/config/local.yaml`.
